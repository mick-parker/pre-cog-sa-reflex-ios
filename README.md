# Pre-Cognitive Situational Awareness Reflex (iOS Prototype)

This iOS prototype implements pre-cognitive situational awareness by detecting sudden loud noises, sudden movement, and rotations using the iPhone's microphone and motion sensors.

## Features
- Loud noise detection
- Sudden movement and rotation detection
- Instant reflex alerts (vibration + screen flash)
- All processing done on-device for privacy

## Usage
1. Clone this repository
2. Open `PreCogSA.xcodeproj` in Xcode
3. Run on a real device (requires microphone and motion permissions)
4. Sudden loud sounds or movement trigger immediate alerts
